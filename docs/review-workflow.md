# 生成审核与提示词改进

生成结束后先答题，交卷判分并保存成绩后进入批量审核；通过后才入库。审核原稿保存到插件的 `recallgen-review-workflow.json`，关闭审核页后可从设置 → 提示词 → 审核反馈 → 待定区重新处理。

- 通过：校验后入库，再进入结果页；已存在的题目保持原来的排程。
- 跳过：保存编辑后的题目，留在待定区。
- 删除：移出待定区。只有填写理由时保留原题、修改稿、操作和生成时的提示词版本作为反馈记录。
- 理由可选。没有理由的操作不进入分析样本。

设置 → 提示词中可按场景筛选、从旧版本派生、比较草稿与历史版本、保存新版本、主动启用或回滚。版本不可覆盖，保存不自动启用。直接编辑当前提示词后保存生效；版本库只展示手动保存的版本，生成时的追溯快照不展示为版本条目。

AI 分析只由用户手动触发。点击分析会向配置的评分 AI 发送最近最多 50 条带理由记录及其提示词。建议必须引用存在的记录、来自同一提示词版本，并包含可以在该版本找到的原文。频率按去重后的引用记录数计算，不代表独立统计验证。用户选择建议，将其应用到对应版本的草稿，再保存新版本并主动启用。

注意：未提交的表单编辑不会自动保存；保存的是生成原稿，或已确认跳过的编辑稿。工作流数据位于独立插件数据文件，目前不包含在既有题库/成绩导出中。真实 AI 效果和思源宿主内交互仍需实际验收。

验证：工作流并发保存、入库失败保留草稿、重复提交、理由记录、批量编辑提交、版本派生/保存/切换与重新加载均有自动测试。全量测试中的既有热力图重复 key 错误另行处理。
